# scripts — 학습·실험 지켜보기

긴 학습이나 실험을 돌릴 때 옆 터미널에서 쓰는 보조 스크립트입니다.

| 파일 | 내용 |
|---|---|
| `watch.ps1` | 학습 진행 상황 실시간 표시 |
| `watch_experiment.ps1` | 실험 또는 학습 로그 실시간 표시 |
| `watch_grid.ps1` · `grid_status.py` | 설정 격자 18판 진행 상황 |
| `watch_pick.ps1` | 넓은 재측정 진행 상황 |
| `keep_checkpoints.py` | 학습이 가중치를 덮어쓸 때마다 회차 번호를 붙여 따로 보관 |
